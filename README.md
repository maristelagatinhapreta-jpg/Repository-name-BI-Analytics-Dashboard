# 📊 BI Analytics Dashboard

Dashboard interativo desenvolvido com **Python** e **Streamlit**[cite: 3] para análise de dados e visualização de indicadores de desempenho (KPIs) de vendas.

---

## 🚀 Funcionalidades

- **KPIs de Vendas:** Acompanhamento rápido de métricas principais (faturamento, ticket médio, volume de vendas).
- **Visualização Gráfica:** Gráficos dinâmicos para análise de tendências e comportamento dos dados.
- **Dashboard Interativo:** Filtros e painéis responsivos construídos com Streamlit[cite: 3].

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e bibliotecas:
- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [Pandas](https://pandas.pydata.org/)
